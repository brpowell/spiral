# Core

The stock pack shipped with Spiral — themes, skins, and visualizers you can use out of the box or as a starting point for your own packs.

## Themes

| Theme | Feel |
| --- | --- |
| **Obsidian** | Deep dark, cool blue |
| **Noir** | Warm charcoal, stark white, red accent |
| **Abyss** | Moonlit indigo, luminous aqua |
| **Grove** | Dark green, soft sage |
| **Parchment** | Warm off-white, sepia |
| **Sprig** | Bright lime on cream paper |

## Skins

- **Vanilla** — Default Spiral player skin

## Visualizers

| Visualizer | Notes |
| --- | --- |
| **Spectrum** | Log-filled frequency spectrum |
| **Bars** | Mirrored frequency bars |
| **Wave** | Mirrored waveform line |
| **Neon Tunnel** | Reactive neon ring tunnel |

Renderers for Spectrum, Bars, Wave, and Neon Tunnel live in this pack and can be reused by other visualizers.
